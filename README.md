# Diplom_1 — юнит-тесты доменной логики Stellar Burgers

Часть дипломного проекта по программе «Инженер по тестированию: от новичка до автоматизатора» (Яндекс Практикум).

Юнит-тесты для конструктора бургеров: проверка логики сборки бургера, работы с ингредиентами и булками, доступа к базе данных.

## Что покрыто тестами

| Класс | Что проверяется |
|---|---|
| `Burger` | добавление и удаление ингредиентов, перемещение ингредиента на новую позицию, расчёт итоговой цены, формирование чека |
| `Bun` | получение имени и цены булки |
| `Ingredient` | получение типа, имени и цены ингредиента |
| `Database` | получение списка доступных булок и ингредиентов |

## Технологии

- Java 11
- JUnit 4
- Mockito — для моков зависимостей
- JaCoCo — контроль покрытия тестами
- Maven

## Как запустить

```
mvn clean test
```

Отчёт о покрытии JaCoCo формируется автоматически в `target/site/jacoco/index.html` после прогона тестов.

## Особенности реализации

- Один тест — одна проверка (без множественных assert в одном методе)
- Класс `Praktikum` (стартовый шаблон) исключён из покрытия
- Код прошёл ревью наставника: исправлены нейминг тестов, убраны магические числа в именах переменных
